# 브릿지 커피 디지털 메뉴판

손님이 테이블의 QR코드를 찍으면 휴대폰으로 보게 되는 **디지털 메뉴판 웹페이지**입니다.
메뉴판은 `index.html` 파일 하나뿐이고, 설치나 서버 없이 브라우저에서 바로 열립니다.

## 주요 기능

- **종류 버튼**
  - 전체 / 커피 / 논커피 / 디저트 버튼이 있고, 누르면 그 종류의 메뉴만 보입니다.
  - 화면을 아래로 내려도 버튼 줄이 위쪽에 붙어 따라옵니다.
  - 아래로 내려온 상태에서 버튼을 누르면, 고른 메뉴의 첫 줄로 자동으로 올라갑니다.
- **시그니처 표시**: 추천 메뉴에 `★ 시그니처` 배지가 붙고, 카드에 보라빛 테두리가 생깁니다.
  - 지금은 아인슈페너와 흑임자 라떼에 붙어 있습니다.
- **오늘 품절 표시**: 품절 메뉴는 흐리게 보이고, 가격 자리에 "오늘 품절"이 뜹니다.
- **전화 걸기 버튼**: 휴대폰에서 누르면 바로 전화가 걸립니다.
- **휴대폰에 맞춘 화면**
  - 가로 폭 390px 휴대폰을 기준으로 만들었습니다.
  - 320px 작은 휴대폰에서도 글자나 버튼이 잘리지 않습니다.
  - 휴대폰을 가로로 돌리면 메뉴 카드가 2개씩 나란히 보입니다.

## 디자인

- **대표 색**: 연보라색(`#A48BF0`)과 하늘색(`#7CC4F2`)
- **스타일**: 공중에 떠 있는 유리판 느낌입니다.
  - 카드가 반투명하고, 뒤 배경이 흐리게 비칩니다.
  - 카드 모서리에 빛이 맺혀서 유리판에 두께가 있는 것처럼 보입니다.
  - 카드 아래에 깊고 부드러운 그림자가 떨어집니다.
- **배경**: 연보라색과 하늘색이 아주 천천히 섞이며 흘러갑니다. 휴대폰에서 '움직임 줄이기'를 켠 손님에게는 멈춰서 보입니다.
- **글꼴**: 프리텐다드를 먼저 쓰고, 없으면 고운 돋움, 그다음 맑은 고딕을 씁니다.
- **크기**: 가격은 크고 진하게 했습니다. 버튼은 손가락으로 누르기 편하게 높이 52px 이상입니다.

## 보는 방법

1. 이 저장소를 내려받습니다.
2. `index.html` 파일을 더블클릭하면 브라우저에서 열립니다.
3. 손님이 QR로 보게 하려면 이 페이지를 인터넷 주소로 올려야 합니다.
   - 예: GitHub 저장소의 **Settings → Pages**에서 `main` 브랜치를 선택하면 무료로 공개됩니다.

> 글꼴은 인터넷에서 불러옵니다. 인터넷이 없으면 맑은 고딕으로 보입니다.

## 메뉴를 고치는 방법

메뉴 정보는 `index.html` **맨 위쪽의 "✏️ 메뉴표"** 한 군데에 모여 있습니다.
여기만 고치고 저장하면 화면의 메뉴 카드가 저절로 바뀝니다.
더 자세한 안내는 메뉴표 위에 한국어 주석으로 적혀 있습니다.

메뉴 한 줄은 이렇게 생겼습니다.

```js
{ name: '아메리카노', price: 4500, desc: '산미가 적은 고소한 원두', signature: 'X', soldOut: 'X' },
```

| 칸 | 뜻 |
|---|---|
| `name` | 메뉴 이름 |
| `price` | 가격 (숫자만) |
| `desc` | 한 줄 설명 |
| `signature` | 시그니처 표시 — `'O'` 켜기 / `'X'` 끄기 |
| `soldOut` | 오늘 품절 표시 — `'O'` 켜기 / `'X'` 끄기 |

| 하고 싶은 일 | 방법 |
|---|---|
| 가격 바꾸기 | `price:` 뒤의 숫자만 바꿉니다. 예: `4500` → `4800` (쉼표나 '원'은 쓰지 않아요) |
| 이름·설명 바꾸기 | 작은따옴표 `' '` 안의 글자만 바꿉니다. |
| **오늘 품절 켜기/끄기** | `soldOut: 'X'`의 **X 한 글자를 O로** 바꿉니다. 다시 팔 때는 X로 되돌립니다. |
| 시그니처 켜기/끄기 | `signature: 'X'`의 X를 O로 바꿉니다. 끌 때는 O를 X로 되돌립니다. |
| 메뉴 추가 | 같은 종류의 메뉴 한 줄을 복사해서 붙이고 내용을 바꿉니다. |
| 메뉴 삭제 | 그 메뉴 한 줄을 통째로 지웁니다. |
| 순서 바꾸기 | 줄을 잘라서 원하는 위치에 붙입니다. |
| 새 종류 만들기 | 디저트 묶음 전체를 복사해서 붙이고, `category` 이름을 바꿉니다. 버튼도 저절로 생깁니다. |

> ⚠️ O와 X는 꼭 **대문자 영어**로 씁니다. 숫자 0이나 한글 ㅇ은 안 됩니다.
> ⚠️ 메뉴 사이의 쉼표(`,`)나 작은따옴표가 빠지면 메뉴가 안 보일 수 있습니다.
> 고친 뒤에는 저장하고 새로고침해서 확인하세요.

### 가게 정보 고치기

가게 이름, 한 줄 소개, 영업시간, 전화번호는 메뉴표가 아니라 파일 가운데 화면 부분에 있습니다.
옆에 `✏️` 표시로 고치는 방법이 적혀 있고, `Ctrl + F`로 "브릿지 커피", "08:00", "tel:"을 검색하면 찾을 수 있습니다.

- 전화번호는 `tel:` 뒤의 숫자와 버튼에 보이는 글자, **두 군데를 같이** 바꿔야 합니다.

### 색깔 바꾸기

`index.html`의 `<style>` 맨 위에 대표 색 설정(`:root`)이 있습니다.
`--lavender`(연보라), `--sky`(하늘색) 같은 이름 옆의 `#` 번호만 바꾸면 됩니다.
예전 디자인 색(갈색·크림색, 오로라 색)도 지우지 않고 그 아래에 남겨 두었습니다.

## 테이블용 QR 코드 만들기

`qr.html`은 메뉴판 주소를 QR 코드로 만들어 주는 도구입니다.
사장님이 쓰는 페이지이고, 손님에게 보이는 화면이 아닙니다.

1. `qr.html`을 더블클릭해서 브라우저로 엽니다.
2. "메뉴판 주소"에 손님이 볼 메뉴판의 인터넷 주소를 붙여넣고 **"QR 만들기"**를 누릅니다.
3. QR 위의 가게 이름과 QR 아래의 안내 문구는 입력칸에서 바꿀 수 있습니다.
4. **"이미지로 저장"**을 누르면 PNG 파일로 내려받습니다.
5. **"인쇄하기"**를 누르면 QR 카드만 A4 한 장에 크게 인쇄됩니다.

- QR을 만들고 저장하고 인쇄하는 것은 **인터넷 없이도** 됩니다.
- 손님이 QR을 찍어 메뉴판을 보려면, 메뉴판(`index.html`)이 **인터넷 주소로 공개되어 있어야** 합니다.
- 인쇄하기 전에 휴대폰 카메라로 QR이 잘 찍히는지 꼭 확인하세요.

## 파일 구성

```
메뉴판/
├─ index.html      메뉴판 전체 (HTML + CSS + JavaScript, 파일 하나)
├─ qr.html         테이블용 QR 코드 만들기 도구
├─ CLAUDE.md       이 프로젝트를 AI와 함께 만들 때 지키는 규칙
├─ README.md       이 문서
└─ 자료/
   └─ 기획시트.png   가게 정보와 메뉴를 정리한 기획 시트
```
